■ fetch() 함수
* 브라우저에서 http 요청을 보내고 응답을 받는 함수
* 응답은 then() 함수와 catch() 함수로 처리

* 일반적인 사용 형태 예시
fetch("요청 url", option)
    .then(response => response.json()) //응답을 json으로 처리
    .then(data => console.log(data)) //데이터를 처리
    .catch(error => console.log(error)) //에러 처리


■ useCallback() 훅
특정 함수가 재성생 되는것을 방지하고 의존성 배열에 있는 값이 변경될때만 해당 함수를 다시 생성한다
즉 불필요한 함수 재생성을 방지하여 렌더링을 최적화하는 용도 

■ useEffect() 훅
컴포넌트가 렌더링 된 후에 실행되어야 하는 코드를 처리할때 사용
리액트에서 렌더링과 관계되지 않은 작업을 비동기적으로 처리

■ useMemo() 함수
의존성 배열의 값에 변화가 없으면 이전에 저장한 값을 반환한다.

■ 고차함수 
다른 함수를 인자로 받거나 함수를 반환하는 함수.
함수를 다루는 함수.
매개변수를 단계적으로 받아 로직을 단계적으로 처리하거나 
매개변수를 한번에 전달받지 않고 단계적으로 받아 단계에 따른 코드의 재사용성을 확보하는 용도

* 예시 1 : 첫 매개변수를 함수로, 두번째 매개변수를 문자열로 받아 처리하는 함수 
* 고차함수 정의
const highOrderFunction = (somefun: () => {}) => (something: string) => {
  // somefun() 함수 호출
  somefun();

  // something 매개변수로 받은 값 처리
  console.log(something);
};

* 고차함수 사용
// 예시로 사용할 somefun 함수
const myFunction = () => {
  console.log('Function is executed');
};

// 고차 함수 호출
const resultFunction = highOrderFunction(myFunction);

// 반환된 함수에 매개변수 전달
resultFunction('Hello, world!');


* 예시2 : 첫번째, 두번째 모두 문자열을 매개변수로 받아 처리하는 함수
* 고차함수 정의
const highOrderFunction = (something1: string) => (something2: string) => {
  console.log(`First: ${something1}, Second: ${something2}`);
};

* 고차함수 사용
// 고차 함수 호출
const partiallyAppliedFunction = highOrderFunction('Hello');

// 반환된 함수에 두 번째 매개변수 전달
partiallyAppliedFunction('World');  // First: Hello, Second: World

■ react-dnd의 드래그  
react-dnd 패키지의 useDrag와 useDrop 훅을 사용하여 구현한다
드래그가 필요한 요소(컴포넌트)에 useDrag와 useDrop을 구현해야한다.

1. useDrag
useDrag는 드래그 시작부터 드래그가 진행되는 동안의 상태를 처리하는 훅. 
즉, 요소를 클릭하여 마우스를 눌러 드래그를 시작하고, 드래그 중인 상태를 관리한다. 

드래그 시작: 요소를 클릭하고 마우스를 잡았을 때 시작.
드래그 중: 드래그 상태가 진행되는 동안 계속해서 마우스를 움직일 수 있다.
드래그 종료: 마우스를 놓기 전에 요소가 드롭 가능한 영역에 있을 때, 드래그가 종료된다.

2. useDrop
useDrop은 드롭 가능한 영역을 정의하고, 드래그된 아이템이 드롭 영역에 도달했을 때의 동작을 처리한다. 
즉, 요소를 클릭하여 움직인 후, 드래그한 요소를 특정 영역에 놓을 때 해당 영역에서의 반응을 처리한다. 

드래그 아이템이 영역 위에 들어갔을 때 (호버): 드래그된 아이템이 드롭 가능한 영역 위에 올려졌을 때의 반응을 처리한다.
드래그 종료: 드래그된 아이템이 드롭 영역에 "놓였을" 때 처리됩니다. 
이때 드롭된 아이템의 데이터를 받아 처리할 수 있다.

요약:
useDrag는 드래그 시작과 진행을 담당한다. 즉, 클릭하여 요소를 잡고 이동하는 동안의 동작을 처리한다.
useDrop은 드래그된 요소가 드롭될 때의 동작을 담당한다. 즉, 요소를 드롭할 위치에 놓았을 때 반응하는 로직을 처리한다.

useDrag는 드래그 하며 이동하는 요소에 대한 처리, useDrop은 드롭될 위치에 대한 처리다.
